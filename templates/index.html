Human-reviewed risk signal

Marketplace Listing Check

Review a listing for possible warning signs. The tool supports your judgement; it does not make decisions about listings.

Listing text is processed locally and not written to disk. Human review decisions are saved in a local database; this demo has no reviewer authentication. Avoid entering personal information.

Transparency and data use
Model
{{ model_id }}, a general-purpose zero-shot classifier. It is not specifically trained for marketplace fraud. Model weights may download from Hugging Face on first use; listing text is processed by this app locally.
Decision policy
Scores at or below {{ review_lower_percent }} are labeled likely legitimate; scores above {{ review_lower_percent }} and below {{ review_upper_percent }} require human review; scores at or above {{ fraud_threshold_percent }} are flagged as potentially fraudulent. These thresholds are provisional, not validated or calibrated.
Explanation
The Explain result button reruns the same classifier with up to three text excerpts omitted and compares scores. This is a local sensitivity check, not access to the model's internal reasoning or proof of causation.
Data and retention
The app does not write listing submissions to disk or send them to a remote inference API. Text is held in server memory while an asynchronous job runs. Its job record expires after {{ job_retention_minutes }} minutes and is removed on the next request; if no later request arrives, it can remain in memory longer until the app restarts. The input limit is {{ input_limit }} characters.
Human control
The app never removes a listing. A reviewer can confirm the warning, mark the listing legitimate, or escalate it. The selected outcome, model result, timestamp, and optional reviewer ID and rationale are saved in a local SQLite database. The listing text is not included. This demo has no login or reviewer authentication; stored decisions do not automatically retrain the model.
Limitations
The score is not a probability or accuracy measure. This prototype has not been validated for accuracy, fairness, or robustness on representative marketplace data.
