Transparency and Data Use

Model
{{ model_id }}, a general-purpose zero-shot classifier. It is not specifically trained for marketplace fraud.
Decision policy
Scores at or below {{ review_lower_percent }} are labeled likely legitimate; scores above {{ review_lower_percent }} and below {{ review_upper_percent }} require human review; scores at or above {{ fraud_threshold_percent }} are flagged as potentially fraudulent.
Explanation
The Explain result check reruns the same classifier with up to three text excerpts omitted. It is a sensitivity check, not access to hidden model reasoning.
Data and retention
Listing text is held in server memory while an asynchronous job runs and is not written to disk. Job records expire after {{ job_retention_minutes }} minutes. The input limit is {{ input_limit }} characters.
Human control
The app never removes a listing. Review decisions, model metadata, and optional reviewer notes are saved locally. The listing text is not included.
Limitations
The score is not a calibrated probability or accuracy measure. This prototype has not been validated on representative marketplace data.
